# Security

This document outlines the security policies and procedures for DolphinScheduler.

## Reporting Security Vulnerabilities

If you discover a security vulnerability in DolphinScheduler, please report it to our security team at security@dolphinscheduler.apache.org.

We follow the Apache Software Foundation's security process:
- https://www.apache.org/security/committers.html

## Security Contact

For security-related inquiries, please contact:
- security@dolphinscheduler.apache.org

## Security Documentation

For more information about security practices and procedures, please refer to:
- https://github.com/apache/dolphinscheduler/blob/dev/docs/docs/en/contribute/join/security.md

## Security Policy

This document outlines the security policies and procedures for DolphinScheduler.

## Security Updates

Security updates are released as soon as possible after a vulnerability is reported and fixed. We recommend keeping your DolphinScheduler installation up to date with the latest version.

## Security Best Practices

To ensure the security of your DolphinScheduler deployment, we recommend:
- Keeping your software up to date
- Using strong authentication and authorization mechanisms
- Regularly monitoring system logs
- Limiting access to sensitive data and functionality
- Following the principle of least privilege

## Acknowledgements

We thank the Apache Software Foundation for providing the security infrastructure and guidance that helps us maintain the security of DolphinScheduler.
