# 任务搜索

进入项目后，选择 **任务 → 任务搜索**。输入任务名称的部分内容，点击 **搜索** 或按回车，即可查找当前项目内包含匹配任务的工作流。清空输入框后，显示项目当前工作流定义所引用的全部任务。

分页结果展示任务名称、任务类型和所属工作流。点击工作流名称可进入其定义页面。同一任务有多个上游依赖时，在同一工作流中只显示一行；被多个工作流引用时，每个工作流分别显示一行。

搜索使用当前工作流定义引用的任务版本，包含从未执行过的任务，以及执行实例已被清理的任务。历史工作流版本、已删除的工作流及没有所属工作流的任务不会出现在结果中。页面只查询定义，不提供独立任务的创建、编辑或执行操作。拥有项目只读权限的用户也可以搜索。

任务名称按字面内容进行包含匹配，`_`、`%` 和 `!` 均作为普通字符处理。

## REST API

`GET /projects/{projectCode}/task-definition/search`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `projectCode` | 是 | URL 中的项目编码，用户须有该项目的访问权限。 |
| `searchVal` | 否 | 任务名称的部分内容，留空或省略时列出项目内符合条件的全部任务。 |
| `pageNo` | 是 | 页码，从 1 开始。 |
| `pageSize` | 是 | 每页结果数量，须为正数。 |

响应采用标准的 `Result<PageInfo>` 格式。`data.total` 是任务与工作流关联的总数，`data.totalList` 中每项包含 `taskCode`、`taskName`、`taskType`、`workflowDefinitionCode` 和 `workflowDefinitionName`。
