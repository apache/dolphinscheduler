# 보안

Apache Software Foundation은 소프트웨어 프로젝트에서 보안 문제를 제거하기 위해 엄격한 입장을 취합니다.Apache DolphinScheduler는 또한 기능과 관련된 보안 문제에 대해 매우 우려하고 있습니다.

DolphinScheduler의 보안에 대한 우려가 있거나 취약성 또는 잠재적인 위협을 발견한 경우 주저하지 말고 [security@dolphinscheduler.apache.org]에 메일을 보내 Apache 보안 팀에 문의하세요.이메일에 프로젝트 이름을 DolphinScheduler로 명시하고 관련 문제나 잠재적인 위협에 대한 설명을 제공해 주세요.또한 문제를 재현하고 복제할 수 있는 방법을 권장해 주시기 바랍니다.Apache 보안 팀과 DolphinScheduler 커뮤니티는 결과를 평가하고 분석한 후 귀하에게 연락할 것입니다.

공개 도메인에 공개하기 전에 보안 이메일을 통해 보안 문제를 신고해 주시기 바랍니다.

## 참고

커밋하기 전에 Apache DolphinScheduler [security-model.md](https://github.com/apache/dolphinscheduler/tree/dev/docs/docs/en/contribute/join/security-model.md)를 따라 문제가 보안 버그인지 확인하세요.
