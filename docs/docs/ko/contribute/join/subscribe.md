# 메일링 리스트 구독

커뮤니티의 최신 소식을 받아보려면 개발 메일링 리스트를 구독하는 것이 좋습니다.

DolphinScheduler를 사용하는 과정에서 질문이나 아이디어, 제안사항이 있으시면 Apache 메일링 리스트를 통해 DolphinScheduler 커뮤니티 구축에 참여하실 수 있습니다.구독 이메일을 보내는 것도 매우 간단합니다. 단계는 다음과 같습니다.

1. dev-subscribe@dolphinscheduler.apache.org로 자신의 이메일 주소를 기재하여 이메일을 보내주세요. 제목과 내용은 임의입니다.

2. 확인 메일을 받고 회신합니다.1단계 완료 후 dev-help@dolphinscheduler.apache.org로부터 확인 메일을 받게 됩니다. (받지 못한 경우 해당 메일이 자동으로 스팸, 프로모션 메일, 구독 메일 등으로 분류되는지 확인해주세요.)그런 다음 이메일에 직접 답장을 보내거나 이메일의 링크를 클릭하여 빠르게 답장할 수 있습니다. 제목과 내용은 임의입니다.

3. 환영 이메일을 받습니다.위 단계를 완료하면 dev@dolphinscheduler.apache.org로 WELCOME이라는 제목의 환영 이메일을 받게 되며 Apache DolphinScheduler 메일링 리스트에 성공적으로 가입하게 됩니다.

# 메일링 리스트 구독 취소

DolphinScheduler에 무슨 일이 일어나고 있는지 알 필요가 없다면 메일링 리스트에서 구독을 취소할 수 있습니다.

메일링 리스트 구독 취소 단계는 다음과 같습니다.

1. 가입한 이메일 주소를 dev-unsubscribe@dolphinscheduler.apache.org로 보내주세요. 제목과 내용은 임의입니다.

2. 확인 메일을 받고 회신합니다.1단계 완료 후 dev-help@dolphinscheduler.apache.org로부터 확인 메일을 받게 됩니다. (받지 못한 경우 해당 메일이 자동으로 스팸, 프로모션 메일, 구독 메일 등으로 분류되는지 확인해주세요.)그런 다음 이메일에 직접 답장을 보내거나 이메일의 링크를 클릭하여 빠르게 답장할 수 있습니다. 제목과 내용은 임의입니다.

3. 작별 이메일을 받습니다.위 단계를 완료하면 dev@dolphinscheduler.apache.org로부터 GOODBYE라는 제목의 작별 이메일을 받게 되며, Apache DolphinScheduler 메일링 리스트 구독이 성공적으로 취소되었으며 dev@dolphinscheduler.apache.org로부터 이메일을 받지 않게 됩니다.
