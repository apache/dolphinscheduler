## 메일링 리스트

- [dev@dolphinscheduler.apache.org](https://lists.apache.org/list.html?dev@dolphinscheduler.apache.org)는 DolphinScheduler에 코드를 기여하려는 사람들을 위한 것입니다.[(구독)](mailto:dev-subscribe@dolphinscheduler.apache.org?subject=(send%20this%20email%20to%20subscribe)) [(구독 취소)](mailto:dev-unsubscribe@dolphinscheduler.apache.org?subject=(send%20this%20email%20to%20unsubscribe))[(아카이브)](http://lists.apache.org/list.html?dev@dolphinscheduler.apache.org)

이메일 사용 시 몇 가지 빠른 팁:

- 이메일 제목에 태그를 지정하면 더 빠른 응답을 받을 수 있습니다.[api-server]: 개방형 API 인터페이스를 얻는 방법은 무엇입니까?

- 태그는 다음을 통해 주제를 식별하는 데 도움이 될 수 있습니다.

- 구성 요소: MasterServer,ApiServer,WorkerServer,AlertServer 등
- 레벨: 초급, 중급, 고급
- 시나리오: 디버그, 방법
- 오류 로그나 긴 코드 예제는 [GitHub gist](https://gist.github.com/)를 사용하고 이메일 내에 해당 코드/로그 몇 줄만 포함하시기 바랍니다.
