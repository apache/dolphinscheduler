# DolphinScheduler 소개

Apache DolphinScheduler는 분산되고 확장하기 쉬운 시각적 워크플로 작업 예약 오픈 소스 플랫폼을 제공합니다.엔터프라이즈 수준의 시나리오에 적합합니다.운영 업무, 워크플로, 전체 데이터 처리 절차를 시각화하는 솔루션을 제공합니다.

Apache DolphinScheduler는 복잡한 빅 데이터 작업 종속성을 해결하고 다양한 빅 데이터 애플리케이션에 대한 데이터 OPS 조정에서 관계를 트리거하는 것을 목표로 합니다.데이터 R&D ETL의 복잡한 종속성과 작업 상태를 모니터링할 수 없는 문제를 해결합니다.DolphinScheduler는 작업의 실행 상태를 적시에 모니터링할 수 있는 DAG(방향성 비순환 그래프) 스트리밍 모드에서 작업을 조합하고 재시도, 지정된 노드의 복구 실패, 작업 일시 중지, 재개 및 종료 등과 같은 작업을 지원합니다.
