# 특징

## 사용이 간편함

- **Visual DAG**: 런타임 제어를 위한 사용자 친화적인 드래그 앤 드롭 워크플로 정의 및 기능입니다.
- **모듈식 작동**: 모듈식으로 쉽게 맞춤화하고 유지 관리할 수 있습니다.

## 풍부한 시나리오

- **다중 작업 유형 지원**: 언어 간 지원을 통해 Shell, MR, Spark, SQL 등과 같은 10개 이상의 작업 유형을 지원하므로 쉽게 확장할 수 있습니다.
- **워크플로 운영**: 워크플로의 시간을 정하고, 일시 중지하고, 재개하고, 중지할 수 있으므로 글로벌 및 로컬 매개변수를 쉽게 유지 관리하고 제어할 수 있습니다.

## 높은 신뢰성

- **신뢰성**: 분산형 설계로 안정성이 보장됩니다.과부하 내결함성 기능을 방지하기 위한 자체 지원 HA 작업 대기열.DolphinScheduler는 매우 강력한 환경을 촉진합니다.

## 높은 확장성

- **확장성**: 다중 테넌시 및 온라인 리소스 관리를 지원합니다.하루 100,000건의 데이터 태스크의 안정적인 운영을 지원합니다.
