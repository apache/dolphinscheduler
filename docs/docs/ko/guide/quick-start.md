# 빠른 시작

Apache DolphinScheduler를 빠르게 체험하려면 [Standalone 설치](installation/standalone.md) 또는 [Docker](start/docker.md) 가이드를 참고하세요.

## 요구 사항

- JDK 1.8+
- MySQL 5.7+ / PostgreSQL 8.2+ 등 지원 데이터베이스
- (선택) ZooKeeper 3.4+ 등 레지스트리

## 기본 개념

- **프로젝트**: 워크플로우·리소스·데이터 소스를 묶는 단위
- **워크플로우 정의**: DAG 형태의 작업 흐름
- **워크플로우 인스턴스**: 워크플로우의 한 번의 실행
- **태스크 인스턴스**: 워크플로우 내 개별 태스크의 한 번의 실행

더 자세한 내용은 [한국어 문서](.)와 [공식 문서](https://dolphinscheduler.apache.org/)를 참고하세요.
